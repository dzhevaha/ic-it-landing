# ic-it — лендинг v3 (2026-11-17)

Третья версия: развитие v1 (Figma `main - 1`, node 2001:49) с правками от 13–17.11.2026.
Онлайн: https://dzhevaha.github.io/ic-it-landing/v3/

Открыть **`index.html`** двойным кликом — работает офлайн на любом компьютере
(three.js и шрифты с кириллицей встроены, сервер и интернет не нужны). Chrome / Edge / Safari, десктоп, планшет, телефон.

## Секции
1. **Герой** — полный логотип, «IT. Simply. Works.», один большой куб из матового стекла с оранжевым ядром. В покое — полный оборот; наведение (на телефоне — тап) поворачивает грань к посетителю, раскрывает её синими пикселями и показывает один тег; клик — любая грань вперёд. Первый экран целиком в окне на любом размере. Логотипы клиентов — бегущая строка.
2. **Solutions We Build** — синее пиксельное поле; при скролле куб открывает нижнюю грань и из неё сыплются пиксели. Змейка: через 1 с появляется еда, след курсора становится змейкой.
3. **Облако тегов** — пиксели поля перетекают в теги вокруг каркасного куба; 11 тем шагами (теги втягиваются в куб, куб поворачивается на 90°, вылетают новые). Кнопка Skip — сразу к финалу. На телефоне один свайп = одна тема (точки привязки, без пролёта через несколько тем).
4. **Финал** — пиксели собираются в 6 стеклянных кубиков с иконками четырёх индустрий; форма email.
5. **Футер** — ISO/IEC 27001:2022, AGB / Datenschutz / Impressum, соцсети, контакты, переключатель языков EN · DE · UA · RU.
6. **Арканоид** под футером — рваная стена пикселей, сквозь неё ломаные шахты и пиксельные лесенки уходят в футер (не выше нижнего края его колонок); ракетка за мышью/пальцем, клик/тап — запуск.
