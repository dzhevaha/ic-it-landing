# ic-it — лендинг v4 (2026-11-17)

Четвёртая версия = v3 + кубы из прозрачного стекла, как у стаканов (герой и финал).
Онлайн: https://dzhevaha.github.io/ic-it-landing/v4/

Открыть **`index.html`** двойным кликом — работает офлайн на любом компьютере
(three.js и шрифты с кириллицей встроены, сервер и интернет не нужны). Chrome / Edge / Safari, десктоп, планшет, телефон.

## Секции
1. **Герой** — полный логотип, «IT. Simply. Works.», один большой куб из прозрачного стекла (как стакан) — внутри чёткий оранжевый куб, который преломляется в гранях. В покое — полный оборот; наведение (на телефоне — тап) поворачивает грань к посетителю, раскрывает её синими пикселями и показывает один тег; клик — любая грань вперёд. Первый экран целиком в окне на любом размере. Логотипы клиентов — бегущая строка.
2. **Solutions We Build** — синее пиксельное поле; при скролле куб открывает нижнюю грань и из неё сыплются пиксели. Змейка: через 1 с появляется еда, след курсора становится змейкой.
3. **Облако тегов** — пиксели поля перетекают в теги вокруг каркасного куба; 11 тем шагами (теги втягиваются в куб, куб поворачивается на 90°, вылетают новые). Кнопка Skip — сразу к финалу.
4. **Финал** — пиксели собираются в 6 кубиков из прозрачного стекла с оранжевым ядром с иконками четырёх индустрий; форма email.
5. **Футер** — ISO/IEC 27001:2022, AGB / Datenschutz / Impressum, соцсети, контакты, переключатель языков EN · DE · UA · RU.
6. **Арканоид** под футером — стена из пикселей складывается в разобранный логотип ic-it (точка, дуга, арка), сверху — налипшие комки пикселей; ракетка за мышью/пальцем, клик/тап — запуск.
